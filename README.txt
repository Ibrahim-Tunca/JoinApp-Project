# Join

Join is a Kanban-based project management app that helps users organize tasks clearly and structure 
them across different workflow stages. Users can create tasks, set priorities, assign contacts, and 
track the progress of individual tasks directly on the board.

The app includes a summary page with important key figures, a board with the status areas "To Do", 
"In Progress", "Await Feedback", and "Done", as well as a contact management section for team 
collaboration. Tasks can be edited, moved, and organized between columns using drag and drop.

This project was created as a learning project as part of the Developer Akademie frontend web development course.
